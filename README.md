# 📸 Photo-Sharing Web Application (Instagram-like Platform)

Một ứng dụng chia sẻ hình ảnh hiện đại được xây dựng dựa trên framework **FastAPI**. Project này mô phỏng các tính năng cốt lõi của Instagram như đăng tải hình ảnh, tương tác và quản lý người dùng.

---

##  Tính năng chính (Key Features)
* **Quản lý người dùng:** Đăng ký, đăng nhập và bảo mật bằng JWT (JSON Web Token).
* **Đăng tải hình ảnh:** Hỗ trợ upload ảnh, lưu trữ và hiển thị ảnh.
* **Tương tác:** Like, Comment và hệ thống Follow giữa các người dùng.
* **Bảng tin (Feed):** Hiển thị các bài đăng mới nhất từ những người bạn đang theo dõi.
* **Tìm kiếm:** Tìm kiếm người dùng và bài đăng theo hashtag.

---

## 🛠 Công nghệ sử dụng (Tech Stack)
* **Backend:** [FastAPI](https://fastapi.tiangolo.com/) (Python)
* **Database:** PostgreSQL / SQLite (SQLAlchemy ORM)
* **Authentication:** OAuth2 với Password hashing (bcrypt)
* **Storage:** Local Storage / Cloudinary (Tùy chọn)
* **Validation:** Pydantic
